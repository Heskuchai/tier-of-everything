# Как добавлять тирлисты и предметы

## Изменить текст или оценку через GitHub

1. Откройте репозиторий, затем `data/tiers.json`.
2. Нажмите карандаш **Edit this file**.
3. Найдите нужный список по полю `title`.
4. Измените `title`, `description`, `criteria` или свойства предмета.
5. При содержательном изменении обновите `updated` сегодняшней датой и добавьте запись в `history`.
6. Нажмите **Commit changes** в ветку `main`.
7. Откройте вкладку **Actions**. Зелёный запуск **Build and publish** означает, что новая версия опубликована. Обычно это занимает несколько минут. Если проверка красная, откройте её журнал: там будет причина. Предыдущая рабочая версия сайта останется доступной.

## Добавить предмет

В массиве `items` нужного списка добавьте объект. Между объектами нужна запятая, после последнего объекта запятая не ставится:

```json
{
  "id": "drinks-cold-cocoa",
  "name": "Холодное какао",
  "emoji": "🥛",
  "tier": "B",
  "note": "Летняя версия любимого напитка. Хорошо со льдом."
}
```

`tier` может быть только `S`, `A`, `B`, `C`, `D` или `F`. `id` состоит из латинских букв в нижнем регистре, цифр и дефисов. Он должен быть уникальным внутри списка. Не меняйте старые идентификаторы ради переименования: к ним привязаны сохранённые версии посетителей. Новые предметы автоматически появятся в авторском уровне даже в ранее сохранённых пользовательских версиях.

В том же списке измените дату и историю, например:

```json
"updated": "2026-11-06",
"history": [
  {"date": "2026-11-06", "text": "Добавлено холодное какао."},
  {"date": "2026-11-05", "text": "Опубликована первая версия."}
]
```

Используйте настоящую текущую дату. Даты из будущего проверка не пропустит.

## Добавить целый тирлист

1. Скопируйте существующий объект из массива `lists` или возьмите [data/new-list.example.json](data/new-list.example.json).
2. Измените `id`, название, описание и предметы. `id` списка должен быть уникальным во всей коллекции.
3. Выберите существующую категорию: `food`, `games`, `tech`, `cinema`, `life`, `misc`.
4. Выберите оформление `theme`: `sand`, `rose`, `sage`, `sky`, `peach`, `lavender`, `butter`, `mint`.
5. Укажите `icon` - эмодзи для обложки, `criteria` - по какому принципу выставлены оценки.
6. Укажите сегодняшние `created`, `updated` и первую запись `history`.
7. Вставьте объект в массив `lists`. Порядок в файле не важен: сайт умеет сортировать сам.

Количество карточек, предметов, категорий и журнал изменений берутся из данных автоматически. Обложки также строятся из эмодзи предметов. Картинки загружать не обязательно. Предел первой версии - 250 предметов на список; очень длинные подборки лучше разделить по темам.

## Добавить категорию

В верхнем массиве `categories` добавьте объект:

```json
{"id": "music", "name": "Музыка", "icon": "🎵"}
```

После этого можно использовать `"category": "music"` в тирлистах. Кнопка категории появится сама.

## Если редактируете на компьютере

Из корня проекта запустите `python build.py`, затем проверки из README. После успешной проверки сохраните изменения в Git и отправьте в GitHub. Не редактируйте `docs/content.js` вместо JSON.
