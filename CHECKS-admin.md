# Проверки панели автора

Дата: 2026-11-05.

- 19 тестов Node: поиск и расстановка, валидация редактора, допустимые адреса изображений, перенос истории, проверка аккаунта, отказ при устаревшем каталоге, атомарная публикация изображений и JSON, отказ при гонке ветки, безопасный импорт копии.
- 8 тестов Python: каталог, ошибки идентификаторов и уровней, недопустимые URL, отсутствующий файл изображения.
- Сборка `python build.py` и синтаксис JavaScript прошли.
- В браузере создан локальный тестовый тирлист, добавлен предмет, изменён уровень, загружен PNG с пересохранением в WebP, добавлена картинка по HTTPS. Эти тестовые изменения не публиковались в каталог.
- Черновик с файлом и URL сохранился после перезагрузки. Скачана копия; ключа GitHub в ней нет.
- Предпросмотр показывает загруженную обложку и выбранный уровень.
- На отдельной локальной QA-копии проверены картинки на публичной странице и экспорт PNG. Скачанный PNG открыт и визуально проверен: изображение попало в свой уровень.
- Проверена узкая раскладка панели: CSS-ширина 390, scrollWidth 375, горизонтального переполнения нет.
- Ошибок JavaScript в проверенных страницах браузера не обнаружено.
- Класс публикации проверен реальным чтением GitHub API: аккаунт Heskuchai и каталог из 8 списков получены успешно. Существующий ключ использовался только в процессе Node/Python, в страницу и файлы не передавался.
- Операции записи класса публикации проверены тестами с подставным API: один коммит для файлов и JSON, актуальный родитель и `force: false`. Личный fine-grained token для браузерной админки должен создать и ввести пользователь при первом подключении. Такая браузерная сессия в этих проверках не выполнялась.
- Программные тесты поиска используют постоянную тестовую коллекцию, чтобы ежедневное изменение настоящего каталога не ломало проверки из-за прежних авторских оценок.
