ЛИЧНЫЙ ДОСТУП

Подключим GitHub.

Для публикации нужен аккаунт Heskuchai и ключ только для репозитория tier-of-everything.

  1. Открой создание fine-grained token ↗.
  2. Выбери срок действия и Only select repositories → tier-of-everything.
  3. В Repository permissions выбери Contents → Read and write. Остальные права добавлять не нужно.
  4. Создай ключ и вставь сюда. Не отправляй его в чат.

Ключ отправляется только в api.github.com и живёт в памяти этой вкладки. После перезагрузки потребуется ввести его снова. Черновики сохраняются отдельно, без ключа.
