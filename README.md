# Тир всего

Минималистичный каталог тирлистов от Heskuchai. В первой коллекции 8 тем и 80 предметов: еда, напитки, игры, рабочий стол, погода, кино и звуки.

**[Открыть сайт](https://heskuchai.github.io/tier-of-everything/)**

## Что работает

- Поиск по названиям, описаниям и предметам внутри списков.
- Несколько категорий одновременно, сортировка, ссылки на отфильтрованную выдачу.
- Отдельная страница каждого тирлиста, объяснения оценок, история изменений.
- Своя версия: перетаскивание мышью или выбор уровня через карточку предмета, включая телефон и клавиатуру.
- Возврат к авторской расстановке, закладки, случайный список.
- PNG-экспорт текущей расстановки и копирование ссылки на авторский список.
- Адаптивный интерфейс, фокус клавиатуры, подписи уровней и reduced-motion.

Рейтинги субъективны. Пользовательские версии и закладки хранятся только в localStorage текущего браузера. Они не передаются автору и не синхронизируются между устройствами. Если хранилище недоступно, сайт показывает сообщение. По ссылке открывается авторский рейтинг; свою версию можно передать картинкой. Аккаунтов, комментариев и общего голосования в этой версии нет.

## Добавление контента

Читайте [CONTENT.md](CONTENT.md). Все списки редактируются в одном файле: [data/tiers.json](data/tiers.json). После сохранения в `main` GitHub Actions проверяет данные, собирает и публикует сайт. Ежедневное добавление выполняет автор, автоматической генерации или расписания нет.

**[Визуальная панель автора](https://heskuchai.github.io/tier-of-everything/admin/)** позволяет добавлять списки, предметы, оценки и изображения через формы. Для публикации используется личный ключ GitHub с доступом Contents только к этому репозиторию; он хранится только в памяти вкладки. Инструкция: [ADMIN.md](ADMIN.md). Публичный интерфейс панели сам по себе не даёт права записи в GitHub.

## Локальный запуск

Python 3.10+ и Node.js 20+ для проверок. Установка пакетов не требуется.

```sh
python build.py
python -m http.server 8768 --directory docs
```

Откройте `http://localhost:8768`. Не открывайте HTML через `file://`: хранилище и загрузки в этом режиме зависят от браузера.

```sh
node --test tests/*.test.cjs
python -m unittest discover -s tests -p "test_*.py"
node --check src/app.js
```

## Структура

| Путь | Что менять |
| --- | --- |
| `data/tiers.json` | Подборки, предметы, оценки, даты и категории |
| `src/app.js` | Интерфейс, маршруты, редактор и PNG-экспорт |
| `src/core.js` | Поиск, фильтры, расстановка и совместимость сохранений |
| `src/admin/` | Визуальный редактор, локальные черновики и публикация в GitHub |
| `media/` | Изображения, загруженные через админку |
| `src/style.css` | Палитра, размеры и адаптивность |
| `src/index.html` | Шапка, подвал и метаданные |
| `build.py` | Проверка содержимого и сборка в `docs/` |
| `.github/workflows/pages.yml` | Автоматическая проверка и публикация |

Сгенерированные файлы `docs/` не редактируйте вручную: сборка заменяет их исходниками. Маршруты используют `#/list/id`, поэтому прямые ссылки работают на GitHub Pages без серверного роутера. Сборка добавляет хеш содержимого к адресам CSS/JS для обновления кеша.

Автопубликация использует [официальный workflow GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages). Источник Pages в настройках репозитория: **GitHub Actions**.

Стартовые обложки собраны из CSS и системных эмодзи. Их внешний вид может отличаться на Windows, Android и iOS. Можно добавить собственные изображения файлом или по HTTPS-ссылке. Шрифты системные, внешних библиотек и трекеров нет. Внешние изображения загружаются с указанного автором сервера.

Код и тексты созданы для авторского проекта Heskuchai при участии AI. Лицензия кода и текстов: MIT. Системные глифы эмодзи принадлежат поставщикам соответствующих шрифтов.
